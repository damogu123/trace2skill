# Real Agent Execution Checklist

Use this checklist before running held-out trajectories for the paper experiment.

## Required Inputs

- A runnable manifest, usually `manifests/heldout_memory_baselines.json`.
- Prompt packs generated by `scripts/build_run_prompts.py`.
- Isolated workspaces prepared by `scripts/prepare_runs.py`.
- A real external agent command that reads `{prompt_path}`, edits `{repo_dir}`, and writes `{trace_path}`.

## Preflight

Run this before executing trajectories:

```powershell
python scripts/preflight_experiment.py manifests/heldout_memory_baselines.json --require-split heldout --require-real-model --require-agent-command --agent-command "<real agent command using {prompt_path} {repo_dir} {trace_path}>" --output-json results/heldout_preflight.json
```

The preflight should have `ready=true` before final experiments.

## Command Shape

The real command should use the placeholders expanded by `scripts/run_external_agent.py`:

```powershell
python scripts/run_external_agent.py manifests/heldout_memory_baselines.json --agent-command "<real agent command using {prompt_path} {repo_dir} {trace_path}>" --require-agent-zero --prepare --skip-existing-trajectories
```

For Codex CLI specifically, see `docs/codex_agent_runner.md`.

Do not use these in final experiments:

- `scripts/mock_agent_patch.py`
- `scripts/run_manual_smoke_pilot.py`
- `--allow-missing-trace`

## After Running

Validate and aggregate:

```powershell
python scripts/validate_trajectory.py trajectories/heldout_memory_baselines
python scripts/compute_metrics.py trajectories/heldout_memory_baselines --tasks tasks --group-by method,split,bug_family --output-json results/heldout_memory_baselines_metrics.json --output-csv results/heldout_memory_baselines_metrics.csv
```

## Evidence Rule

Only trajectories produced by a real external agent on held-out tasks should be treated as experiment evidence. Smoke trajectories, mock trajectories, and manual trajectories are harness validation only.
