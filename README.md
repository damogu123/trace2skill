# Evaluating Low-Shot Procedural Skill Transfer in Language-Agent Debugging

This repository contains the evaluation harness, artifacts, and manuscript
source for a study of low-shot procedural memory transfer in language-agent
debugging.

The core experiment asks whether an agent can induce a natural-language
`SKILL.md` artifact from a small number of debugging trajectories and transfer
that procedural memory to within-family held-out PyBugHive tasks with comparable
repair success and lower recorded process cost.

## What Is In This Repository

- `artifact_agenticdev2026/`: curated upload-ready artifact for the AgenticDev
  2026 submission. Start here for the clean experiment/data package, including
  `README.md`, `DATA_SELECTION.md`, `REPRODUCE.md`, and `FILE_INVENTORY.tsv`.
- `scripts/`: task import, validation, run-manifest construction, agent
  execution wrappers, trajectory recording, metric computation, and paper-result
  generation.
- `schemas/`: JSON schemas for tasks, run manifests, trajectories, and agent
  traces.
- `tasks/`: benchmark task definitions used by the harness.
- `memory/`: frozen memory artifacts used as experimental conditions.
- `manifests/`: runnable experiment manifests.
- `prompts/`: prompt templates and generated prompt packs.
- `trajectories/`: validated trajectory JSON records used for analysis.
- `results/`: aggregate metrics, setup reports, and cleanup reports.
- `paper/`: manuscript source, bibliography, figures, tables, reviews, and build
  notes.
- `docs/`: operational documentation for the harness and GitHub packaging.

Large or generated local artifacts are intentionally excluded from Git:
`runs/`, `workspaces/`, `logs/`, LaTeX intermediates, old rendered screenshots,
and `data/external/`.

## Claim Boundaries

The primary paper claim is deliberately narrow:

- primary same-model evidence is the first-six PyBugHive `black` hard-smoke
  tasks under `gpt-5.3-codex`;
- Auto `SKILL.md` solves 5/6 tasks, tied with the best primary baselines;
- the main empirical signal is process efficiency, not universal solve-rate
  dominance;
- one explicit negative-transfer case is recorded;
- supplementary `gpt-5.5` structural-control results should not be presented as
  proof that the canonical `SKILL.md` format is necessary for solvability.

For the latest project state, read `SESSION_HANDOFF.md`.

## Quick Start

The harness scripts are Python standard-library only. Use Python 3.12+ for the
harness itself. Some benchmark checkouts may require their own pinned Python
environments or WSL/Linux-compatible execution.

Validate task and trajectory records:

```powershell
python scripts/validate_task.py tasks
python scripts/validate_trajectory.py trajectories
python scripts/validate_run_manifest.py manifests
```

Validate the curated AgenticDev artifact:

```powershell
python scripts/validate_task.py artifact_agenticdev2026/tasks
python scripts/validate_trajectory.py artifact_agenticdev2026/trajectories
python scripts/validate_run_manifest.py artifact_agenticdev2026/manifests
```

Recompute metrics from trajectories:

```powershell
python scripts/compute_metrics.py trajectories/pybughive_hard_smoke --tasks tasks --group-by method,task_id --output-json results/recomputed_hard_smoke_by_task.json --output-csv results/recomputed_hard_smoke_by_task.csv
```

Run a Codex-backed agent experiment after preparing a model-specific manifest:

```powershell
python scripts/run_external_agent.py manifests/pybughive_hard_smoke_codex.json --agent-command "python scripts/run_codex_agent.py --prompt-path {prompt_path} --repo-dir {repo_dir} --artifacts-dir {artifacts_dir} --trace-path {trace_path} --model gpt-5.3-codex" --require-agent-zero --prepare --skip-existing-trajectories
```

See `docs/codex_agent_runner.md` and
`docs/real_agent_execution_checklist.md` before launching paid or long-running
runs.

## Manuscript Build

The AgenticDev/ASE Workshop version is built from `paper/main.tex` with ACM
`acmart` and SVG conversion through Inkscape:

```powershell
cd paper
latexmk -pdf -jobname=main_agenticdev -shell-escape -interaction=nonstopmode -file-line-error main.tex
```

Full build notes are in `paper/BUILD.md`.

## Reproducibility Notes

- For the most compact upload target, use `artifact_agenticdev2026/`. For a
  fuller GitHub-facing repository export, use `github_export/` generated by
  `scripts/create_github_export.py`.
- Frozen files under `memory/pybughive/test_failure_triage/` should not be
  edited and reused with old results. Any changed memory artifact needs a new
  condition name, manifest, and rerun.
- Raw `runs/` logs were removed from the cleaned workspace after the validated
  trajectory JSON records and `artifact_agenticdev2026/` package were created.
  The canonical process evidence for the paper is in `trajectories/` and
  `artifact_agenticdev2026/trajectory_sets/`.
- `data/external/` was removed from the cleaned workspace. Curated PyBugHive
  task metadata remains under `data/pybughive/` and `data/pybughive_hard/`.
- Reference patches are used to verify task reproducibility and solvability;
  they are not shown to the held-out repair agent.
